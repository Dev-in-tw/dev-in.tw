# ADR 0006：不收集身分個資

- 狀態：Accepted（擁有者已於 2026-10-14 確認，見 `docs/PLAN.md` §7）
- 日期：2026-10-14
- 詳細設計：`docs/PLAN.md`

## 背景

舊系統申請子網域時要求填身分證字號、地址、電話、生日，明文存放，`/user/info` 原樣回傳（D-02、D-21）。違反個資法的最小蒐集原則，業務上也用不到。

## 決策

- 只保存 GitHub 身分（numeric id、login、顯示名稱、頭像、帳號建立時間）與 GitHub primary verified email（僅用於濫用聯絡與重要通知）。
- 不收身分證字號、地址、電話、生日。
- 舊 MongoDB 與所有備份排程銷毀，並留下處理紀錄（PLAN.md §3.14）。

## 影響

- 個資外洩風險大幅降低。
- 檢舉者 IP 只存 `sha256(ip + REPORT_IP_SALT)`；稽核紀錄的 IP 90 天後清空。

## 放棄的東西

無法做實名驗證（本來就不需要）。
