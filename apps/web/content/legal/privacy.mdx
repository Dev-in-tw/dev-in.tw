## 5. 公開的資料

- **DNS 紀錄是公開資料**。任何人都能查詢你子網域的 DNS 紀錄，包括 TXT 紀錄的內容，請不要在紀錄裡放個人資料。

## 6. 第三方服務

- **GitHub**（登入）：處理 OAuth 登入。網頁上的頭像直接從 GitHub 的 `avatars.githubusercontent.com` 載入，所以 GitHub 會看到瀏覽者的 IP 位址與瀏覽器資訊。
- **Lazco DNS**（DNS 代管）：`dev-in.tw` 的 DNS 由 Lazco 自建的權威 DNS 服務代管，你的 DNS 紀錄會同步到那裡並回應公開的 DNS 查詢。這項服務同樣由 Lazco 營運，同步時只傳送 DNS 紀錄本身，不傳送你的帳號資料。網站的連線直接到 Lazco 管理的伺服器，HTTPS 也在我們的伺服器上解開，**不再經過 Cloudflare 代理**。
- **Cloudflare**（人機驗證 Turnstile、備份儲存）：你在申請子網域或送出檢舉時，Turnstile 會在你的瀏覽器執行，Cloudflare 會收到你的 IP 位址與瀏覽器資訊；我們的伺服器向 Cloudflare 驗證時也會一併附上你的 IP。資料庫的每日備份存放在 Cloudflare R2（物件儲存），由 Lazco 管理，只有負責維運的小組成員能存取。
- **Discord**（內部告警）：有新的待審申請或檢舉時，系統會發送通知到維運小組的私人頻道，內容只有必要的營運資訊，例如子網域名稱、申請人的 GitHub 帳號名稱、待審原因或檢舉類別，不含 email 與 IP。
- **公共 DNS 解析器**（Cloudflare、Google、Quad9、TWNIC Quad101）：你在控制台檢查紀錄是否生效時，我們的伺服器會向這些解析器查詢你的網域名稱，不會傳送你的個人資料。

這些服務依各自的隱私權政策處理資料。

## 7. Cookie 與瀏覽器儲存

我們只使用兩個必要的 cookie，都設定為 HttpOnly 與 Secure，網頁上的 JavaScript 讀不到：

- `__Host-dit_session`：登入狀態。閒置 14 天或登入滿 60 天就會失效，登出時立即失效。
- `__Host-dit_oauth`：登入過程中防止偽造請求，約 10 分鐘後失效。

下列資料只存在你的瀏覽器（localStorage 或 sessionStorage），**不會傳給我們**：

- 主題（淺色／深色）、快捷鍵與動畫偏好
- 指令面板的輸入歷史
- 服務狀態頁在這台裝置上的檢查紀錄
- 尚未登入時填寫的申請草稿（關閉分頁後清除）

## 8. 保存期限

- **帳號資料**：保存到你刪除帳號為止，刪除流程見第 9 條。
- **登入 session**（含 IP 與 User-Agent）：session 失效或被登出後 7 天內刪除。
- **稽核紀錄**：保存 1 年後刪除；其中的 IP 位址在 90 天後清除。
- **子網域與 DNS 紀錄**：保存到你釋出子網域或刪除帳號為止。被停權的子網域，資料會保留到解除停權或釋出為止。
- **名稱冷卻紀錄**：名稱釋出後保存 30 天，到期刪除。
- **同意紀錄**：保存到你刪除帳號為止。
- **檢舉紀錄**：處理期間完整保存。檢舉處理完成（成立或不成立）滿 1 年後，系統會自動清除其中的聯絡 email、IP 的雜湊值、檢舉說明，以及與檢舉人帳號的關聯，只保留子網域名稱、檢舉類別、處理結果與時間，作為統計與防止重複濫用的依據。在那之前，你也可以請求我們刪除你留下的聯絡 email。
- **應用程式日誌**：以容器日誌輪替保存，最長 30 天，過期後自動刪除。
- **資料庫備份**：每天備份一次，保留最近 14 份（約 14 天），存放在 Lazco 管理的 Cloudflare R2，過期的備份自動刪除。已刪除的資料可能在備份中留存到該份備份過期為止（最長約 14 天），期間只會在災難復原時使用，不會用於任何其他用途。

## 9. 刪除帳號時會發生什麼

在設定頁刪除帳號後：

1. **立即**：清除你的 email 與顯示名稱、登出所有裝置，你名下所有子網域開始釋出。DNS 紀錄會從 DNS 服務撤下並刪除，名稱進入 30 天冷卻期，**無法復原**。
2. **子網域清除完成後**：系統每小時執行的清理工作會刪除你的帳號資料，包括 GitHub 數字 ID、帳號名稱、頭像網址、帳號建立日期、登入 session（含 IP 與 User-Agent）、同意紀錄與尚未完成的轉移。正常情況下會在幾個小時內完成。DNS 服務暫時故障、紀錄一時清不掉時，系統會自動重試並通知維運小組處理，清除完成後一樣會刪除帳號資料。
3. **會留下的資料**：
   - 稽核紀錄依第 8 條的期限保存（1 年，其中的 IP 在 90 天後清除）。為了資安稽核與爭議處理，稽核紀錄中的 GitHub 帳號名稱與子網域名稱會保留到該筆紀錄刪除為止，但不再連結到你的帳號。
   - 釋出名稱的冷卻紀錄保存 30 天，不連結到你的帳號。
   - 你送出的檢舉不再連結到你的帳號，並依第 8 條在處理完成滿 1 年後清除聯絡 email 與內容。
   - 資料庫備份中的資料，會在該份備份過期時一併刪除（最長約 14 天）。

刪除帳號前，你可以先在設定頁下載你的資料（第 11 條）。

帳號資料刪除前，你如果又用同一個 GitHub 帳號登入，刪除帳號的申請就會取消，但已經開始釋出的子網域不會恢復。

帳號被停權時，無法在設定頁自行刪除帳號，請寫信到 [hello@dev-in.tw](mailto:hello@dev-in.tw) 申請。

## 10. 資料安全

- 全站使用 HTTPS。登入使用 OAuth 的 state 與 PKCE 防護。
- 資料庫只保存 session token 的雜湊值，不保存明文 token。
- 本服務的應用程式日誌不記錄 cookie、token 與 email，IP 只記錄加鹽雜湊值。
- 稽核紀錄只能新增、不能修改。
- 只有負責維運的小組成員能存取正式環境的資料。

如果發生個人資料被竊取、洩漏、竄改或其他侵害事故，我們會查明狀況、採取應變措施，並依個資法及相關法令通知受影響的使用者，必要時通報主管機關。

## 11. 你的權利

依個資法第 3 條，你可以就你的個人資料行使下列權利：

2. 請求製給複製本
3. 請求補充或更正
4. 請求停止蒐集、處理或利用

你的 email 與部分 GitHub 資料，會在你每次登入時依 GitHub 上的資料更新。要更正這類資料，請先在 GitHub 修改，再重新登入。

## 12. 不提供資料的影響
