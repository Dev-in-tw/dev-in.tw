# 隱私權政策

最後更新：2026 年 10 月 14 日

Dev-in.tw 由 **Lazco Labs（拉資科科技有限公司，Lazco Corporation）**營運，由 Lazco 組成的小組負責維運。我們的原則很簡單：**只收服務運作真正需要的資料。**

## 我們蒐集什麼

| 資料 | 來源 | 用途 |
|---|---|---|
| GitHub 數字 ID、帳號、顯示名稱、頭像網址、帳號建立日期 | GitHub（你授權登入時） | 辨識帳號、顯示在控制台、評估濫用風險（新帳號需審核） |
| 主要且已驗證的 email | GitHub | 濫用聯絡與重要服務通知，**不寄行銷信** |
| 子網域、描述、DNS 紀錄 | 你輸入 | 提供服務 |
| 登入裝置的瀏覽器資訊與概略 IP | 你的瀏覽器 | 讓你在設定頁管理登入裝置、防止濫用 |
| 操作紀錄（稽核紀錄） | 系統 | 安全稽核與處理檢舉 |
| 檢舉內容與選填的聯絡 email | 檢舉人 | 處理檢舉 |

我們**不會**蒐集身分證字號、地址、電話或生日，也**不會**存取你的 GitHub repo 或保存 GitHub access token。

## Cookie

我們只使用一個必要的登入 cookie（`__Host-dit_session`），設定為 HttpOnly 與 Secure，網頁上的 JavaScript 讀不到。登入過程中會短暫使用另一個 cookie 防止偽造請求。我們不使用廣告或追蹤 cookie，也不放第三方分析工具。

主題（淺色／深色）與快捷鍵等偏好存在你瀏覽器的 localStorage，不會傳給我們。

## 公開的資料

只有你在子網域設定開啟「公開展示」時，子網域名稱、描述、你的 GitHub 帳號與頭像才會出現在成員牆與首頁地圖。預設不公開。子網域的 DNS 紀錄本身是公開資訊，任何人都能查詢。

## 第三方服務

| 服務 | 用途 | 會收到的資料 |
|---|---|---|
| GitHub | 登入 | 登入流程所需的資料 |
| Cloudflare | DNS 代管、人機驗證（Turnstile） | 你的 DNS 紀錄；驗證時的瀏覽器資訊 |
| Lazco 自有主機 | 網站與資料庫 | 上述所有資料 |

## 保存期限

- 登入 session：過期 7 天後刪除
- 稽核紀錄：保留 1 年，其中的 IP 在 90 天後清除
- 刪除帳號後，個人資料會立即刪除，僅保留法律或安全稽核必要的紀錄
- 資料庫備份保留 14 天

## 你的權利

依個人資料保護法，你可以查詢、閱覽、請求複本、補充更正、停止蒐集處理利用或刪除你的個人資料。大部分可以直接在控制台完成，其他請寫信到 hello@dev-in.tw。

隱私相關問題：hello@dev-in.tw；資安問題：security@dev-in.tw。
