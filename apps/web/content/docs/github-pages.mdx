# GitHub Pages

把 `你.dev-in.tw` 接到 GitHub Pages，大約三步。

## 一鍵設定（推薦）

1. 到控制台的子網域「總覽」，在「快速設定」選 **GitHub Pages**
2. 確認「GitHub 使用者或組織」（預設是你的帳號），按「預覽變更」
3. 看過要新增與刪除的紀錄後按「套用」

會產生：

```
@  1  IN  CNAME  you.github.io.
```

## 在 GitHub 那邊

1. 打開 repo 的 **Settings → Pages**
2. 在 **Custom domain** 填 `你.dev-in.tw`，按 Save
3. 等 DNS 檢查通過後，勾選 **Enforce HTTPS**（憑證由 GitHub 簽發，通常幾分鐘）

## 網域驗證（建議）

GitHub 建議驗證自訂網域，避免別人在你的子網域上架站。到 GitHub 的 **Settings → Pages → Add a domain** 取得驗證碼，在一鍵設定的「網域驗證碼」欄位填入，就會多產生一筆：

```
_github-pages-challenge-you  1  IN  TXT  "驗證碼"
```

## 常見問題

- **顯示 `Domain does not resolve`**：DNS 還在傳播，先到「傳播檢查」確認四個 resolver 都看到 CNAME 了。
- **想用 `www.你.dev-in.tw`**：把一鍵設定的「套用在哪個名稱」改成 `www` 即可。
