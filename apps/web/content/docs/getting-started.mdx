# 快速開始

Dev-in.tw 讓你免費拿到一個 `你的名字.dev-in.tw`，然後在網頁上自己管理 DNS。整個流程大概五分鐘。

## 1. 用 GitHub 登入

到[登入頁](/login)按「使用 GitHub 登入」。我們只會讀你的公開資料與主要 email，**不會**碰你的 repo，也不保存 GitHub token。

## 2. 挑一個名字

回到[首頁](/)，在終端機提示列輸入想要的名字：

- 3–32 個字元，只能用小寫英文、數字與連字號
- 開頭與結尾不能是連字號，也不能有連續的 `--`
- 1–2 個字元的名字目前保留中

看到 `NXDOMAIN → 可以申請 ✓` 就按 Enter。少數名字（例如和知名品牌很像，或 GitHub 帳號建立未滿 30 天）會先經過人工審核，通常一天內完成。

每個人最多 **2 個**子網域，每個子網域最多 **10 筆**紀錄。

## 3. 指向你的網站

開通後到控制台的「總覽」，選一個平台用一鍵設定，或到「紀錄」自己新增：

```
@      300  IN  CNAME  you.github.io.
www    300  IN  CNAME  you.github.io.
```

新增後紀錄會先顯示 `[ PENDING ]`，通常一秒內變成 `[ SYNCED ✓ ]`。接著到「傳播檢查」看看 Cloudflare、Google、Quad9 與 TWNIC Quad101 是不是都看到了。

> 小技巧：在任何頁面按 `⌘K`（Windows 是 `Ctrl+K`）打開指令面板，輸入 `add cname www you.github.io` 就能直接新增紀錄。
